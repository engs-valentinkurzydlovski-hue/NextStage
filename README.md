# NextStage

## Sobre o projeto

O NextStage é um site sobre o universo dos videogames. Seu objetivo é apresentar jogos e plataformas, permitindo que os usuários conheçam diferentes opções do mundo dos games.

## Conceitos aplicados

- **Usabilidade:** menu simples e navegação entre as páginas.
- **Experiência do Usuário (UX):** organização dos conteúdos em cards e identidade visual gamer.
- **Acessibilidade:** botão de alto contraste e textos alternativos nas imagens.
- **Responsividade:** adaptação do layout para diferentes tamanhos de tela.

## Escolhas de design

Foi escolhido um tema escuro com detalhes roxos para criar uma identidade visual relacionada ao universo dos videogames.

Os jogos e plataformas foram organizados em cards para facilitar a visualização e a navegação.
